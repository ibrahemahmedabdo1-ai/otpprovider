توثيق API — إرسال OTP مباشرة من تطبيقك

مفتاح واحد، طلب واحد، وحساب خصم رصيد فوري وشفاف حسب قاعدة التسعير الحالية.

🔑 المصادقة

كل حساب عميل يقدر يولّد مفتاحين من لوحة التحكم ← API Keys: مفتاح test (للتجربة، مالوش قيمة مالية ومستهلكش رصيدك الحقيقي) ومفتاح production (بيستهلك رصيدك الفعلي بعد شحن باكدج). ابعت المفتاح في الهيدر: 

Authorization: Bearer otpp_live_xxxxxxxxxxxxxxxxxxxx
POST/v1/otp/send

إرسال رمز تحقق عبر واتساب أو إيميل، وخصم الرصيد المطلوب تلقائيًا حسب قاعدة التسعير الحالية للقناة.

curl -X POST https://YOUR-DOMAIN/v1/otp/send \
  -H "Authorization: Bearer otpp_live_xxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "channel": "whatsapp",
    "recipient": "+201234567890"
  }'
// Node.js
const res = await fetch("https://YOUR-DOMAIN/v1/otp/send", {
  method: "POST",
  headers: {
    "Authorization": "Bearer otpp_live_xxxxxxxxxxxx",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({ channel: "whatsapp", recipient: "+201234567890" })
});
const data = await res.json();
الحقلمطلوبالوصف
channelنعمwhatsapp أو email (المزيد قريبًا: SMS, Telegram, Voice)
recipientنعمرقم الهاتف بصيغة دولية أو البريد الإلكتروني
countryاختياريلتطبيق تسعير خاص بدولة معينة لو مفعّل من الأدمن

الرد يشمل: ok, creditsCharged, remainingBalance, verificationId. لو فشل الإرسال فعليًا يتم استرداد الرصيد المخصوم تلقائيًا في نفس الطلب.

⚠️ ملاحظات مهمة

  • لا يوجد أي مسار يتجاوز محرك التسعير — كل استهلاك رصيد لازم يعدي من /v1/otp/send.
  • مفاتيح test لا تستهلك رصيدًا حقيقيًا ولا يُسمح باستخدامها في بيئة إنتاج.
  • كل عملية إرسال وخصم رصيد تُسجَّل في سجل حركة الرصيد (Ledger) ويمكن مراجعتها من لوحة التحكم.
